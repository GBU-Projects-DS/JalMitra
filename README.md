# JalMitra

Smart plant irrigation guide for India and the world. Hindi and English.
Water calculator, watering planner, crop guide, schemes and a voice assistant.

## Files
- index.html : page structure and content
- style.css  : all styling (light and dark theme)
- script.js  : calculator, My Plants, assistant, voice, loading screen

## Run locally
Open index.html in a browser. No build step needed.

## Deploy
Push these files to a GitHub repository, then connect it to GitHub Pages, Netlify or Cloudflare Pages.

## Notes
- My Plants are saved only in the visitor browser (localStorage).
- Numbers are estimates. Confirm scheme details on official portals.
